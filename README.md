# Coffee_shop_webpage
☕ CoffeeTime Cafe Website

A modern and responsive coffee shop website built using HTML, CSS, and Bootstrap 5.
This project features animated sections, responsive layouts, menu cards, hover effects, and a stylish cafe-themed UI design.

🚀 Features

Responsive Navigation Bar

Animated Hero Section

Coffee Menu Cards

About Cafe Section

Contact Form UI

Smooth Hover Effects

Responsive Design

Social Media Footer Icons
